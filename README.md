# ⛵ Vildsund Bådelaug

Mobilvenlig sejlsimulator i three.js. Vip telefonen for at styre, vælg mellem kortene **Øerne** og **Vilsund**, og oplev et døgn på 2 minutter.

Spil: https://jbacim.github.io/sailor/

Højdedata for Vilsund: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (Mapzen). Georeferering ud fra vejnettet i © [OpenStreetMap](https://www.openstreetmap.org/copyright)-bidragydere.
